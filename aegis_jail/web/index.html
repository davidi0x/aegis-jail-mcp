What Autopilot does

A responder can contain, never approve

  • Jail an MCP server that runs with full rights
  • Discard a run that tripped a wire
  • Mark what it handled, with a note you can read here
  • Re-trust a tool whose definition changed
  • Apply an agent's changes to your project

Keep it running

Start Autopilot at login

$ aegis watch install

systemd on Linux, launchd on macOS, a scheduled task on Windows. Remove it with aegis watch uninstall.

Quick start

Setup

Four steps, then your AI clients use Aegis without you typing commands.

  1. Install Aegis

    Python 3.10 or newer, no dependencies.

    pip install git+https://github.com/davidi0x/aegis-jail-mcp

  2. Start Autopilot in the background

    It watches your MCP configs, runs and projects, and serves this dashboard.

    aegis watch install

  3. Give Claude Code the Aegis tools

    The plugin adds the Aegis MCP server, a guard that keeps credentials out of reach, and hooks that tell Claude about open events at the start of each session.

    claude plugin marketplace add davidi0x/aegis-jail-mcp && claude plugin install aegis@aegis

  4. Give Codex (OpenAI) the Aegis tools

    Add the Aegis MCP server to ~/.codex/config.toml. Any other MCP client works the same way: it starts aegis mcp-server.

    [mcp_servers.aegis]
    command = "aegis"
    args = ["mcp-server"]
